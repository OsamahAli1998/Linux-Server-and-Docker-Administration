# Linux Server and Docker Administration

This repository contains my second assignment from the **System Administration (1DV721)** course at Linnaeus University.

## Project Overview

In this assignment, I configured and administered Linux environments using a remote Ubuntu server, Docker and VirtualBox.

The work included:

* Connecting securely to a remote server using SSH keys
* Updating and examining an Ubuntu server
* Checking disk usage, users, services and open ports
* Installing and configuring Apache and MariaDB
* Enabling CGI and running Bash scripts through Apache
* Creating an automated backup script
* Installing and configuring Docker
* Building custom Docker images
* Managing containers with Docker Compose
* Running Apache and CGI inside a container
* Installing Ubuntu in VirtualBox
* Testing SSH, file transfers and desktop applications
